# เว็บเพจแนะนำตัว
ใบงานปฏิบัติการ Git พื้นฐาน

## ผู้จัดทำ
- วาสนา นุ่มวงศ์ รหัสนักศึกษา 662422060175

## ไฟล์ในโปรเจกต์
| ไฟล์ | หน้าที่ |
|------|---------|
| index.html | หน้าแรกของเว็บเพจ |
| about.html | หน้าประวัติส่วนตัว |
| css/style.css | รูปแบบการแสดงผล |
| js/script.js | สคริปต์สลับและจดจำธีม |
| .gitignore | กำหนดไฟล์ที่ไม่ต้องติดตาม |

## วิธีเปิดใช้งาน
เปิดไฟล์ `index.html` ด้วยเว็บเบราว์เซอร์

## รายการ branch
| branch | หน้าที่ |
|--------|---------|
| main | สายหลักและไฟล์ตั้งต้น |
| feature/header | ส่วนหัวแสดงชื่อและรหัสนักศึกษา |
| feature/about | หน้าประวัติส่วนตัว |
| feature/style | ไฟล์ CSS และ `.gitignore` |
| feature/script | สคริปต์สลับธีม |
| docs/readme | เอกสารประกอบโครงงาน |
| experiment/merge-conflict | ทดลองและแก้ merge conflict |
